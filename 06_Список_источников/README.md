# Раздел 6. Список использованных источников

В этой папке собраны материалы для списка литературы курсовой работы:

- Официальная статистика (Росстат, ИСИЭЗ НИУ ВШЭ).
- Аналитические материалы (CNews, TAdviser, IT Russia).
- Реестр российского ПО (Минцифры).
- Техническая документация (QGIS, PostgreSQL, ГИС «Панорама»).
- Международные стандарты (OGC).
- Материалы вендоров (Геоскан, Роскосмос).

Всего: не менее 20 источников, из них не менее 30% за последние два года.
