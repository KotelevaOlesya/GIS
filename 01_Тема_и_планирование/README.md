# Раздел 1. Тема и планирование

В этой папке собраны материалы, относящиеся к первому разделу чек-листа:

- Карточка рынка (границы рынка, продукт, потребитель, территория, период).
- Оценки объёма рынка из разных источников.
- Участники рынка и их роли.
- Продукты рынка (реестр российского ПО и зарубежные аналоги).
