# Раздел 1. Введение

В этой папке собраны материалы для введения курсовой работы:

- Актуальность темы (рынок ГИС, импортозамещение, НСПД).
- Объект и предмет исследования.
- Цель и задачи работы.
- Методы исследования (анализ документов, сравнительный анализ, кейс-анализ).
- Границы рынка (продукт, потребитель, территория, период).
- Информационная база: краткое описание использованных источников (статистика Росстата, ИСИЭЗ НИУ ВШЭ, реестр ПО и т.д.).
