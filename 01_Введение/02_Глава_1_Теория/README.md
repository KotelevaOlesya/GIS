# Раздел 2. Глава 1. Теоретические основы

В этой папке собраны материалы для первой главы курсовой работы:

- Границы рынка ГИС (продукт, потребитель, территория, период).
- Оценки объёма рынка (IT Russia, Университет Иннополис).
- Участники рынка и их роли (вендоры, интеграторы, заказчики, регуляторы).
- Продукты рынка (ГИС «Панорама», ZuluGIS, «Аксиома», ArcGIS и др.).
- Жизненный цикл типового ГИС-продукта (7 этапов).
- Технологическая платформа продукта (6 слоёв).
- Путь данных на рынке ГИС (5 шагов: источники, хранение, обработка, аналитика, решение).
- Роль искусственного интеллекта (ИИ) в обработке пространственных данных.
