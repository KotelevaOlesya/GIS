# 📚 Раздел 2. Глава 1. Теоретические основы

> *В данной главе рассматриваются теоретические аспекты функционирования рынка ГИС: от определения границ и участников до жизненного цикла продукта.*

### 📊 Оценки объёма рынка
В ходе исследования были проанализированы различные оценки объёма рынка ГИС:
*   По оценке **IT Russia** (2024 г.), объём рынка ГИС в РФ составил более **165 млрд руб.** (включая решения, услуги и данные).
*   По оценке **Университета Иннополис** (2021 г.), объём госзакупок ГИС составил **2,8–3,8 млрд руб.**
*   *Ограничение:* оценки не сопоставимы напрямую из-за разного охвата (широкий рынок vs. только госзакупки).

### 🔄 Жизненный цикл продукта
1. Планирование
2. Анализ требований
3. Проектирование
4. Разработка / настройка
5. Внедрение
6. Эксплуатация
7. Завершение
> **Особенность:** Главные риски возникают при подключении существующих наборов пространственных данных, а не на этапе установки ПО.

### 🗺 Путь данных на рынке ГИС
1. **Источники** (Росреестр, Росстат, Роскосмос) → *слабое звено: различия форматов и систем координат.*
2. **Хранение** (PostgreSQL/PostGIS) → *слабое звено: отсутствие единого каталога.*
3. **Обработка** (QGIS, «Панорама») → *слабое звено: ручные операции.*
4. **Аналитика и BI** (Yandex DataLens) → *слабое звено: несовместимые показатели.*
5. **Решение** (Карты, дашборды) → *слабое звено: отсутствие метаданных о точности.*

### 🤖 Роль искусственного интеллекта
ИИ применяется для автоматической векторизации снимков и классификации объектов (например, модуль «Панорама Vision»). Однако ИИ пока не заменяет контроль специалиста, а лишь ускоряет рутинные операции.
