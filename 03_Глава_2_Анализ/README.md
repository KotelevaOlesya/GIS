# Раздел 3. Глава 2. Анализ текущего состояния рынка

В этой папке собраны материалы для второй главы курсовой работы:

- PEST-анализ макросреды (политические, экономические, социальные, технологические факторы).
- SWOT-анализ для АО КБ «Панорама» (сильные, слабые стороны, возможности, угрозы).
- Анализ пяти сил Портера (конкуренция, потребители, поставщики, новые игроки, заменители).
- Карта рынка по методологии Magic Quadrant (лидеры, визионеры, нишевые игроки).
- Кривая Hype Cycle (стадии технологий: ИИ, облака, 3D-ГИС, мобильные ГИС).
