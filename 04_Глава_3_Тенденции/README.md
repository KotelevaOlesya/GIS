# 📈 Раздел 4. Глава 3. Тенденции и рекомендации

> *В данной главе систематизированы ключевые тренды рынка ГИС и сформулированы практические рекомендации для его участников.*

### 🚀 Ключевые тренды рынка
1. **Переход к облачным и мобильным решениям.** Вендоры активно предлагают SaaS-версии, растёт выручка облачных провайдеров (Ростелеком, VK Cloud).
2. **Внедрение ИИ в обработку ДЗЗ.** Компьютерное зрение используется для автоматической векторизации снимков (модуль «Панорама Vision»).
3. **Консолидация вокруг лидеров.** Рынок тяготеет к крупным экосистемам («Панорама», «ПОЛИТЕРМ»), способным предложить полный стек решений.

### ⚠️ Ограничения развития
*   **Высокая стоимость переключения** для заказчиков (6–12 мес. миграции).
*   **Дефицит квалифицированных ГИС-специалистов.**
*   **Санкционные риски** в части инфраструктуры (серверы, ОС).
*   **Высокие барьеры входа** для новых игроков (сертификация ФСТЭК, Реестр ПО).

### 💡 Рекомендации участникам рынка
| Для кого | Рекомендация |
|---|---|
| **Лидеры** («Панорама») | Усиливать дифференциацию через ИИ и интеграцию с BI-системами |
| **Нишевые игроки** | Фокусироваться на узких сегментах (кадастр, ЖКХ, ДЗЗ) |
| **Новые игроки** | Искать ниши, где открытый код (QGIS) не даёт готового решения |
