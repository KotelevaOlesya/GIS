# Раздел 4. Глава 3. Тенденции и рекомендации

В этой папке собраны материалы для третьей главы курсовой работы:

- Подтверждённые тренды рынка (переход к облачным ГИС, внедрение ИИ, мобильные приложения).
- Ограничения развития рынка (высокая стоимость переключения, дефицит кадров, санкционные риски).
- Рекомендации для вендоров и новых игроков.
